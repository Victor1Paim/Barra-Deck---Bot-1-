# Base de conhecimento

Coloque aqui documentos da empresa que o Deck One pode **ler** (`.md`, `.txt`, `.csv`, `.json`):
manual de processos, tabela de preços, lista de contatos, políticas internas...

O conteúdo desta pasta é ignorado pelo Git (exceto este README), para os dados da empresa
não irem para o repositório público. Mude o caminho com `DECK_CONHECIMENTO` no `.env`.
